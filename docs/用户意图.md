# 用户的潜在聊天与交互意图

## 课程规划,管理与自适应路径

用户尝试通过自然语言管理他们的学习路线。

- 新建系统课程
- 继续当前课程学习
- 触发补救学习
- "这门课太难/太简单了,调整一下" — 难度/节奏重定
- "跳过这一节,我已经会了" — 手动标记 mastery

## 学习状态与进度查询

- 我学到哪里了
- 我的哪些概念还比较薄弱
- 这周我学习了什么内容
- 距离学会 X 我还差什么

## 概念解析与对话

日常的学习问题与讨论(与AI导师性格相搭配)

- 直观比喻与解析(如: 解释一下什么是复利)
- 启发式追问(如果变量变大,结果会怎么样)
- 代码与技术实现解析(输出结构化Code代码块)

## 评估,测试与练习

测量学生的掌握度(Mastery), 更新用户facts

- 随堂临时测验,触发Quiz Card生成
- 帮我复习上周学的内容 - 基于Learning events 生成复习lesson
- 答题反馈与指引,AI生成Feedback与不剧透答案的hint
- 错题回顾:"我之前哪道题做错了,再考我一次"

## 交互式可视化与仿真模拟

- 图表/关系可视化
- 数学/信号交互模拟
- 物理场景动力学模拟
- 3D科学空间探索

## 个人化与记忆管理

- "记住我_是高中生 / 我数学基础弱"
- "我更喜欢_多举例子、少讲公式" — 教学风格偏好
- "你记错了,我不是……" — 纠正 facts
- "忘掉我刚才说的" — 隐私删除,这个在产品上必须有出口

## 情感与动机支持

- "我学不会,太难了" — 挫败安抚 + 降阶重讲
- "我坚持不下来" — 目标拆解、学习计划
- 考前焦虑、拖延求助

## 越界与护栏意图(必须显式设计)

- 直接要作业答案(与你的 no-spoiler hint 策略冲突,需要定义边界)
- 完全无关的闲聊/工具化使用("帮我写周报")
- 超出 KG 覆盖范围的学习请求 — 你已经有 freeform gate,这就是它的对话侧意图
