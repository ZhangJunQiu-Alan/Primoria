## Priority Rationale

- High priority stories (US-01, US-02) directly address the core value proposition: active, practical learning.
- Medium priority story (US-03) improves retention and personalization after core learning loop is working.
- Low priority story (US-04) adds social support and can be staged after core learning flow stabilizes.

## Acceptance Criteria (Baseline)

### US-01 Interactive Learning by Action

- Learner can run and edit Python examples in an interactive environment.
- Learner can retry after mistakes and continue without losing progress.
- Feedback loop is visible in the same lesson flow.

### US-02 Solve Real Problems, Not Watch Lectures

- Each topic includes practice-focused tasks, not lecture-only pages.
- System shows hints or feedback after learner attempts.
- Learner sees meaningful progression from attempt to correction.

### US-03 Adaptive Study Rhythm

- Learner can follow short study sessions with manageable steps.
- Flow supports variable pace and simple milestone tracking.
- System avoids forcing a fixed time block for all learners.

### US-04 One-on-One Study Partner

- Learner can request/find a study partner with compatible goals.
- Learner can establish a shared routine.
- Feature clearly supports motivation and persistence outcomes.
