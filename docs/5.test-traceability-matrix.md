## Defect Tracking Workflow

1. Run automated and manual checklist tests.
2. If failure occurs, create issue using:
   - [bug_report.yml](/Users/sithuhein/Documents/GitHub/Primoria/.github/ISSUE_TEMPLATE/bug_report.yml), or
   - [system_test_defect.yml](/Users/sithuhein/Documents/GitHub/Primoria/.github/ISSUE_TEMPLATE/system_test_defect.yml)
3. Link issue in this matrix.
4. Link fix PR/commit in issue.
5. Re-test and update status.
