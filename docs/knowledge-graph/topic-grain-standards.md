# 知识图谱划分标准

用于推断「一个概念该不该独立成节点、节点间连什么边」。

状态：当前 KG 内容规范，2026 年 7 月。source 位于
`data/knowledge-graphs/source/`；自动门禁运行
`pnpm --filter @primoria/web validate:kg`。本规范解释内容判断，不能替代脚本校验与人工学科审核。

## 节点 (concept node)

**定义**:一个能独立出 quiz 题检验的最小概念 = 单一可诊断技能/结果。

**该拆**(同时满足):
- 子技能**分别考、分别会错**(高可分性)。例:收敛半径 vs 端点判别、麦克劳林公式 vs 常见展开式。
- 拆后每个子节点仍能积累足够 quiz 证据来估 mastery。

**不该拆**(命中任一):
- 是作为整体应用的查找表/公式集(如基本求导公式、基本积分公式)。
- 拆后**证据碎片化**:子节点 quiz 太少,mastery 估不准,反而害诊断。
- 子技能的薄弱已被**上游节点**捕获,拆它只是信息冗余。

> 一句话:拆「会分别做错的技能」,不拆「一起记忆的清单」。

**背景概念**(如基本初等函数)按函数族/最小单元拆开,让诊断能把瓶颈追溯到根因(「三角函数本身不熟」)。

## 边

只保留一类:
| 类型 | 形态 | 用途 |
|---|---|---|
| 先修 prereq | DAG,node`from` 先于 `to`node | 诊断病灶 + 排课 |

**先修强度**:`hard`(没学会就学不了)/ `soft`(有帮助非必需)。诊断时 hard 优先级高于 soft。

**砍掉**没有消费方的关系(相似/等价/共同使用/易混淆…)——除非有明确机制要用,否则只是维护负担。

**跨 topic / 跨学科先修边允许**,前提:节点 `id` 全局唯一。

## 每次改图后必校验

- id 无重复;边端点、`topic` 引用都存在。
- 先修边**无环**(必须是 DAG,才能拓扑排序排课)。
- 无入边的起点概念数量可控、符合预期(应是该学科的真正入口)。
- 每个 topic 保持 2–3 个 concept；节点同时具备非空 `name` 与 `name_zh`。
- 修改跨学科边后运行 `pnpm --filter @primoria/web db:seed:kg-cross`；修改图后按导入 runbook 重建派生 topic 图与 embeddings。
