# Artifact review

## When to use

Use this skill when the user asks to review, critique, improve, polish, or validate a learning artifact or workspace output.

Do not use it as a generic chat critique when there is no artifact or concrete output to inspect.

## Instructions

1. Identify the artifact's intended learner outcome.
2. Check clarity, correctness, interaction quality, and learning value.
3. Prioritize issues that block understanding.
4. Suggest specific edits instead of vague quality comments.
5. Keep praise brief and useful.
6. If update tools are available, ask approval before modifying shared artifacts or tasks.

## Output

Return:

- quick verdict
- top 2-4 issues or strengths
- concrete improvement suggestions
- recommended next action

Avoid overwhelming the user with a long audit unless they request it.
