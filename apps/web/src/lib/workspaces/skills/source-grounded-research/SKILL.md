# Source-grounded research

## When to use

Use this skill when the user asks for research, references, current information, comparison of sources, or evidence-backed summaries.

Do not pretend to have checked sources if no search or retrieval tool was used.

## Instructions

1. Clarify the research question and scope.
2. Separate known context from claims that require sources.
3. Use approved search/retrieval tools when current or precise information matters.
4. Summarize sources in your own words.
5. Mark inference clearly.
6. Prefer a small number of high-quality sources over broad unsourced claims.

## Output

Return:

- short answer
- evidence bullets with source labels when available
- uncertainty or limitations
- suggested next research step

If external tools or MCP connections are needed, follow the approval policy before sending workspace data out.
