# Socratic questioning

## When to use

Use this skill when the learner asks for help understanding, solving, debugging, or deciding, especially when they have not shown their current reasoning yet.

Do not use it for urgent factual lookups, explicit requests for a direct final answer, or administrative workspace actions.

## Instructions

1. Identify the smallest next reasoning step.
2. Acknowledge the learner's goal in one short sentence.
3. Ask exactly one focused question that moves them forward.
4. If they are stuck, give one small hint before any full explanation.
5. Do not reveal the complete solution unless they ask for it or have already tried.
6. Tie the question to the current chat/task context when available.

## Output

Return at most:

1. one short acknowledgement
2. one guiding question
3. one optional hint

Keep the response short enough for group chat. Do not create tasks or artifacts unless a tool approval flow asks for it.
