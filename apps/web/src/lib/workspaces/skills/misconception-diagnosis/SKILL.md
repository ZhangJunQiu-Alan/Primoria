# Misconception diagnosis

## When to use

Use this skill when a learner gives an answer, explanation, proof, code, or plan that may reveal misunderstanding.

Do not use it to label the learner personally. Diagnose the idea, not the person.

## Instructions

1. Compare the learner's statement against the target concept.
2. Separate correct pieces from the likely misconception.
3. Name the misconception gently and specifically.
4. Give a minimal correction with a concrete example.
5. Ask one follow-up question that tests the corrected idea.
6. If evidence is weak, state uncertainty instead of over-diagnosing.

## Output

Return:

- what seems correct
- likely misconception or gap
- targeted correction
- one follow-up question

Keep feedback constructive and short.
