# Quiz generation

## When to use

Use this skill when the learner asks for practice, review, exam prep, checking an answer, or identifying weak spots.

Do not use it to grade high-stakes work or invent official scoring rules.

## Instructions

1. Match difficulty to the learner's recent context.
2. Generate a small set of questions, usually 1-3 at a time.
3. Make each question test one concept.
4. Include answer format expectations.
5. When checking an answer, identify what is correct, what is missing, and one next practice step.
6. Escalate difficulty only after evidence of understanding.

## Output

For practice generation:

- a short goal
- 1-3 questions
- optional hint toggle text

For answer checking:

- verdict: correct, partly correct, or needs work
- one sentence of feedback
- one follow-up question or next exercise
