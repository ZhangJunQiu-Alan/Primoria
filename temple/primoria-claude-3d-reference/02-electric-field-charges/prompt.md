# Prompt

Create a single self-contained HTML file for a 3D interactive STEM learning widget. Use Three.js. Include clear labels, a compact control panel, smooth mouse drag rotation, a reset button, responsive layout, and a polished educational visual style. The widget should teach the concept visually, not just decorate it. Keep it suitable for embedding inside an AI tutor chat card.

Topic: Electric field around positive and negative charges. Show draggable positive and negative charges in a 3D scene, field vectors sampled around them, field-line curves, charge-strength controls, a reset button, and concise labels explaining attraction/repulsion. Name the artifact file electric-field-charges.html and return the result as a single downloadable HTML artifact.
