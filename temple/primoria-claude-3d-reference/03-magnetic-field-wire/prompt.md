# Prompt

Create a single self-contained HTML file for a 3D interactive STEM learning widget. Use Three.js. Include clear labels, a compact control panel, smooth mouse drag rotation, a reset button, responsive layout, and a polished educational visual style. The widget should teach the concept visually, not just decorate it. Keep it suitable for embedding inside an AI tutor chat card.

Topic: Magnetic field around a current-carrying wire. Show a vertical wire, circular magnetic field lines around it, direction arrows using the right-hand rule, a current direction toggle, current strength slider, field-strength readout, smooth drag-to-rotate camera, and a reset button. Name the artifact file magnetic-field-wire.html and return the result as a single downloadable HTML artifact.
