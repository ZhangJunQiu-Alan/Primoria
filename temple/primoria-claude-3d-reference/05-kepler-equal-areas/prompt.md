# Prompt

Create a single self-contained HTML file for a 3D interactive STEM learning widget. Use Three.js. Include clear labels, a compact control panel, smooth mouse drag rotation, a reset button, responsive layout, and a polished educational visual style. The widget should teach the concept visually, not just decorate it. Keep it suitable for embedding inside an AI tutor chat card.

Topic: Planet orbit and Kepler's second law. Show a planet moving on an elliptical orbit around a star, sweep equal areas over equal time intervals, highlight two equal-area sectors, include speed variation indicators, time-step or eccentricity controls, drag-to-rotate camera, play/pause, and reset. Name the artifact file kepler-equal-areas.html and return the result as a single downloadable HTML artifact.
